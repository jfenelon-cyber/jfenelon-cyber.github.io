## GitHub Pages upload
1. Open your GitHub repository.
2. Remove or replace the old website files.
3. Upload everything inside the Portfolio-Website folder.
4. Commit the changes.
5. In repository Settings > Pages, select Deploy from a branch.
6. Choose the main branch and /root.
7. Save and wait a few minutes for the site to publish.
