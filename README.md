# Jephete Fenelon Cybersecurity Portfolio

This is a complete responsive portfolio website built with HTML, CSS, and JavaScript.

## Open the website

1. Extract the ZIP file.
2. Open the folder.
3. Double-click `index.html`.

## Important updates before publishing

Open `index.html` and replace:

- Contact information is already added.
- Confirm the GitHub URL is correct.
- Add your resume to `docs/Jephete-Fenelon-Resume.pdf`.

## Add your project PDFs

Place your PDF files in the `docs` folder and rename them to match the links already used in `index.html`.

The file `docs/PROJECT-FILE-NAMES.txt` lists every expected filename.

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload everything inside this folder.
3. Open repository **Settings**.
4. Select **Pages**.
5. Choose **Deploy from a branch**.
6. Select the `main` branch and `/root`.
7. Save.

The site uses no framework and requires no installation.
