# Jephete Fenelon Professional Multi-Page Cybersecurity Portfolio

This package contains a complete multi-page static website:

- Home
- About
- Projects
- Certifications
- Skills
- Resume
- Contact
- Six individual project case-study pages

## Publish on GitHub Pages

1. Back up your current repository.
2. Upload all files and folders from this package to the repository root.
3. Keep or add your existing `docs` folder for the resume and PDF evidence.
4. Commit the changes.
5. In GitHub repository settings, confirm Pages deploys from the main branch and root folder.

The site uses your professional portrait in `assets/images/jephete-fenelon.png`.
